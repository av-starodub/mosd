# Требования

## Функциональные
- CRUD для процессов и их версий.
- CRUD справочника типов процессов.
- Получение latest‑версий процессов.
- Фильтрация/сортировка/пагинация списка процессов.
- Поддержка вариантов скорости процесса (rate options).
- Поддержка режима передачи результата (FULL_ONLY/BATCHED).
- Расчёт ожидаемого времени выполнения (следующий этап).

## Нефункциональные
- Версионирование процессов.
- Валидация входных данных.
- Безопасные ограничения на API (MVP).
- Документирование API через Swagger/OpenAPI (dev‑профиль).
