## Реализовано (MVP текущее)

### Функциональные
- CRUD (create/get/list) для процессов и их версий.
- CRUD (create/get/list) для `ProcessType`.
- CRUD (create/get/list) для `OperationType`.
- Получение latest-версий процессов.
- Фильтрация latest-списка процессов по `type`.
- Расчёт ожидаемого времени выполнения через `POST /api/v1/scheduler/estimate`.
- Возврат детального расчёта по items/processes/queues.
- Выбор скорости в расчёте через `rateSelectionMode` (`OPTION | OVERRIDE`) с XOR-валидацией.

### Нефункциональные
- Версионирование процессов (`processKey + version`).
- Бизнес-валидации уникальности и совместимости данных.
- Детеминированный результат расчёта при одинаковом входе.
- Документирование API через Swagger/OpenAPI (dev-профиль).

## MVP backlog (в работе)

### Функциональные
- постановка входных сущностей в реальный план выполнения;
